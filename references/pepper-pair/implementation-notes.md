# Pepper Popper and M.A.D. Pepper

Both source recipes accept both ingredient orders. Pepper Popper uses Cherry Bomb and Jalapeno, and M.A.D. Pepper uses Doom-shroom and Jalapeno. The Replanted save pairs are `Jalapeno/Cherrybomb` and `Jalapeno/Doomshroom`. Plant Library registers both results with `UnlockPolicy.Never`. Seed planting and Lawn Glove use the existing fusion transaction.

## Source evidence

The local English 4.0.5.2 build was inspected with [REA](https://github.com/morluto/rea), version 6.10.1, and its Ghidra 12.2 provider. The GameAssembly SHA-256 is `48096b917ee6aaf6e35c95c98e666a4399a9e0c3d5adbab727cee941eccf2d42`. The project was seeded from REA IL2CPP metadata. Analysis used the original program bytes and the selected method entries without full-program auto-analysis.

- `CherryJalapeno` (source plant 1179) initializes the attribute countdown in `Awake` (`0x462070`). `AttributeEvent` (`0x462040`) removes the rolling plant from the occupied tile. `Update` (`0x4623a0`) advances it at 10 source world units per second and corrects the lane height. `OnTriggerStay2D` (`0x4620c0`) calls `BoardAction.CreateCherryExplode` for eligible same-row contacts and applies 0.8 units of knockback. The inherited damage and crush slots resolve to the no-op body at `0x3eab80`. The `BombCherry` constructor sets the small blast radius to 1.5 source units and the row range to one. The source description confirms a one-second fuse, 300 blast damage, and an additional 15× hit against the source-only Nian zombie.
- `DoomJalapeno` (1317) manually activates `AnimExplode` (`0x462e70`). `Crashed` (`0x463270`) uses the same payload with a reentry guard. `CreateFireLine` (`0x41f060`) burns the row, and `SetDoom` (`0x420af0`) supplies the radius-five ash blast. Its crater flag is set only at the pepper origin. Each other occupied tile on the row loses its plants and emits a doom blast. Each destroyed plant independently rolls `Random.Range(0,4)` for a drop containing its original type. The source description confirms manual activation and 1800 ash damage.
- `Fertilize.Upgrade` (`0x682810`) changes a positive existing attribute timer. Replanted applies the shared half-second cap to the Popper countdown. M.A.D. Pepper has no automatic detonation timer. Fertilizer applies ordinary health restoration to both.

Raw REA evidence is local under `pvzreplanted/.test-runs/task1-20261120-pair/`. Key files are `rea-fusion-metadata.json`, `rea-prepared-CherryJalapeno.json`, `rea-prepared-DoomJalapeno.json`, `rea-followup-BoardAction.json`, `rea-lifecycle-functions.json`, `rea-bomb-functions.json`, `rea-text-read-1179-0.json` and `rea-text-read-1317-0.json`. The text records came from REA byte search and bounded reads of the local `LawnStrings.json` artifact.

## Replanted implementation

`PepperFusions` uses the shared source clock, native Plant slots and the existing retained-actor query scopes for the rolling plant. The fuse, roll state, contact phase and board position use native save fields. The roll vacates its tile and ends at the right board boundary. Native rectangles and the shared ground-target rules replace Unity collision layers. Cherry and Doom effects use the existing native damage, particle and sound adapters. Both peppers deal direct effects. Neither launches a separate projectile from these abilities.

M.A.D. Pepper activates from a normal cursor click or controller confirm. The controller also accepts confirm while a seed packet is held and the tile has no valid planting or fusion action. The controller path uses the existing gamepad coordinate mapping. A crush also detonates it. The action consumes its own plant first, then applies the fire, doom and plant-removal effects. Victims are captured per cell with generation checks before death callbacks. Dropped packets use Replanted’s native seed type. The current packet representation has no fusion marker, so a destroyed fusion drops its underlying native seed type. Existing reactive-pot crater protection applies. The source-only Nian zombie and source Odyssey modifiers are unavailable in Replanted and have no corresponding effects here.

The ports reference the existing Bell Pepper and Solar Flare model and portrait resources. The presentation uses original English and German descriptions of the Replanted behavior. The native particle and Foley adapters supply combat feedback.
